# Experiments

One directory is reserved for each of the nine SUARA experiments. Put experiment-specific code, notes, and reproducible setup instructions in its directory. Keep shared pipeline code in `../main_pipeline/`.

Active workspaces: E1 (pitch detection), E3 (song analysis), and E6 (voice embedding). The E3 and E6 implementations and setup instructions are directly in `E3/` and `E6/`.
